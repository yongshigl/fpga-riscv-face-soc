# 基于自主 RISC-V/INT8 异构架构的双摄人脸识别 SoC

本项目基于紫光同创 PG2L200H-6-FBB676 FPGA，实现了自主 RISC-V 处理器、INT8 视觉加速器、双 OV5640 摄像头、DDR3 帧缓存、板上人脸对齐、特征提取与身份检索。

## 目录

- `设计代码/`：项目源码与工程文件，包括 RTL、处理器与视觉 SoC、固件、主机侧程序、测试平台、构建脚本、第三方源码和 PDS 配置。

## 主要模块

- 自主 RV32I RISC-V 处理器、分支预测、Cache、异常与 CSR
- INT8 MAC 阵列及卷积、深度卷积、残差、池化、上采样等算子支持
- 双 OV5640 图像采集、DDR3 帧缓存、图像对齐和量化处理
- YuNet 人脸检测与 MobileFaceNet 特征提取、身份检索
- CoreMark 评测固件、串口协议、网页控制台和上板测试脚本
- 模块级测试平台、SoC 回归脚本和 PDS 综合布局布线工程

## 使用说明

详细的目录说明、构建方法和上板运行方法见 [`设计代码/README.md`](设计代码/README.md)。
